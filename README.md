# 🎓 Student Portfolio Builder

A full-stack web application built using **PHP, MySQL, HTML, CSS, Bootstrap, and JavaScript** that allows students to create, manage, and share their professional portfolios online. The application provides a secure authentication system and an easy-to-use interface for showcasing academic and personal achievements.

## 🌐 Live Demo

🔗 **Live Website:** https://student-portfolio-builder.42web.io/

> Replace the URL above if your deployed project is hosted at a different location.

---

## ✨ Features

- 🔐 Secure User Registration & Login
- 🔒 Password Hashing for User Security
- 👤 Student Profile Management
- 📝 Create & Edit Portfolio
- 🎓 Academic Details
- 💻 Skills Section
- 🚀 Projects Showcase
- 📜 Certifications
- 📞 Contact Information
- 🌍 Public Portfolio View
- 📱 Fully Responsive Design
